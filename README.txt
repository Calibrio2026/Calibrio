CALIBRIO DESKTOP
================

1. Open the Calibrio-Desktop folder.
2. Double-click Calibrio.exe.
3. You may also double-click Start-Calibrio.cmd; it now launches Calibrio.exe.

The launcher starts Calibrio at http://localhost:3001 on this computer.
Start-Calibrio.cmd delegates directly to Calibrio.exe so both entry points use
the exact same app view and saved local data.
Calibrio.exe opens Brave when it is installed; otherwise it opens the Windows
default browser. It does not force Microsoft Edge.

To close Calibrio, close the browser window.
If Windows Firewall asks about Node.js, select Cancel; Calibrio only listens on
this computer.

Keep Calibrio.exe and Start-Calibrio.cmd together with the app, runtime, and
logs folders. You may create a desktop shortcut to either launcher, but do not
move the launcher by itself.
